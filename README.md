### Descripción del Juego

El juego genera un número oculto dentro de un rango definido según la dificultad que se seleccione. Se tiene un número limitado de intentos para adivinarlo. Conforme se ingrese las respuestas, el programa te indicará si tu número es "Muy bajo" o "Muy alto", permitiendo ajustar el siguiente intento que se tenga. Además, cuenta con un sistema de puntuación y una tabla de mejores resultados por partida

### Niveles de Dificultad:

* **Fácil**: Rango del 1 al 20, con 8 intentos.

* **Medio**: Rango del 1 al 50, con 7 intentos.

* **Difícil**: Rango del 1 al 100, con 6 intentos.

### Requisitos Previos

* **Python** (versión 3.x recomendada).

### Cómo Ejecutar el Juego

1. Clonar este repositorio o descarga el archivo del juego (`adivina_numero.py`) en la computadora.

2. Abrir una terminal  y navegar hasta la carpeta donde se encuentra el archivo.

3. Ejecutar el siguiente comando para iniciar el juego:

   ```
   python adivina_numero.py
   
   ```

4. Sigue las instrucciones en pantalla para ingresar tu nombre, elegir la dificultad y comenzar a jugar.
